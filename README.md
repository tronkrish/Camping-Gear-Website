# 🏕️ Camping Gear Website  

🚀 A beautifully designed **Camping Gear Website** built using **HTML, CSS, and JavaScript**. This project showcases different camping products with an engaging and responsive UI.

## 🔗 Live Demo
👉 [View the Camping Gear Website](https://tronkrish.github.io/Camping-Gear-Website/)

## 📜 Features
✅ **Responsive Design** - Works on all devices (Mobile, Tablet, Desktop).  
✅ **Interactive UI** - Hover effects, smooth transitions, and animations.  
✅ **Camping Gear Showcase** - Display products with descriptions.  
✅ **Image Gallery** - A stunning collection of camping gear images.  
✅ **Contact Form** - Users can get in touch for inquiries. 

## 🛠️ Technologies Used
- 🏗️ **HTML** - Structure of the webpage.  
- 🎨 **CSS** - Styling, animations, and responsiveness.  
- 🛠️ **JavaScript** - Interactive elements and dynamic effects.
